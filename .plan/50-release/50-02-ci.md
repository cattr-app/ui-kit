## Цель
Workflow'ы `Deploy documentation` и `Publish Package` работают с pnpm-скриптами 2.0 и прогоняют проверки.

## Факты
- `deploy-docs`: `pnpm build:docs` → upload `dist`. Новый выход docs — `dist-docs` (см. 40-01), путь в `upload-pages-artifact` обновить.
- `publish`: `pnpm build:package` → заменить на `pnpm build`; добавить шаги `pnpm lint`, `pnpm test` перед сборкой. `npm publish` оставить (`prepublishOnly` не должен дублировать build — проверить).
- Добавить workflow `ci.yml` на `pull_request` и push в `main`/`feat/vue-3`: install (frozen), lint, format:check, test, build, build:docs. Кэш pnpm store через `actions/setup-node` `cache: pnpm` (требует `corepack enable` до setup-node или `pnpm/action-setup`).

## Критерии приёмки
- `actionlint` без ошибок (запустить через docker `rhysd/actionlint:latest`, контейнер удалить).
- Имена шагов и команды соответствуют `package.json`.

## Проверка
```sh
docker run --rm -v "$PWD:/repo" -w /repo rhysd/actionlint:latest -color
```
