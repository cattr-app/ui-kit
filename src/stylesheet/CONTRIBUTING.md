# Contributing to Cattr UI Style

Styles live in `src/stylesheet/src`: `index.scss` is the entry point, `variables/` holds component variables, `mixins/` and `core/` hold shared helpers and fonts.

Build the stylesheet with `scripts/node.sh pnpm --filter cattr-ui-style build` from the repository root.

Before opening a pull request, make sure the build passes and describe the change in the PR body.
