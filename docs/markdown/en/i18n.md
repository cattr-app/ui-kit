# Internationalization

----

The default language of `Cattr UI` is `English`. If you want to use Chinese or other languages, you can follow instruction below.

## Built-in Locale

Import a language pack and pass it to the plugin:

```js
import { createApp } from 'vue'
import CattrUI from '@amazingcat/cattr-ui'
import de from '@amazingcat/cattr-ui/locale/de'
import App from './App.vue'

createApp(App).use(CattrUI, { locale: de }).mount('#app')
```

The language can also be changed later with `import { locale } from '@amazingcat/cattr-ui'` and `locale(de)`.

## Compatible with vue-i18n

Pass a translation hook `(key, values) => string` in the `i18n` option. If the hook returns `null` or `undefined`, the string from the built-in locale (`en-US` or the one passed in `locale`) is used.

```js
import { createApp } from 'vue'
import { createI18n } from 'vue-i18n'
import CattrUI from '@amazingcat/cattr-ui'
import enLocale from '@amazingcat/cattr-ui/locale/en-US'
import zhLocale from '@amazingcat/cattr-ui/locale/zh-CN'
import App from './App.vue'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    en: { ...enLocale },
    zh: { ...zhLocale }
  }
})

createApp(App)
  .use(i18n)
  .use(CattrUI, { i18n: (key, values) => i18n.global.t(key, values) })
  .mount('#app')
```

Note that `i18n.global.t` returns the key itself for a missing message, not `undefined`, so the fallback to the built-in locale does not work in that case. Either add the `at.*` keys to the vue-i18n messages (as above), or check the key first: `(key, values) => (i18n.global.te(key) ? i18n.global.t(key, values) : undefined)`.

## Supported Languages

| Language | Filename |
|--- |--- |
| Chinese | zh-CN |
| English | en-US |
| German | de |
| Korean (South Korea) | ko-KR |
| Portuguese (Brazil) | pt-BR |
| Persian (Iran) | fa-IR |

If your target language is not included, you are more than welcome to contribute: just add another language config to [here](https://github.com/cattr-app/ui-kit/blob/main/src/locale/lang/) and create a pull request.
