# 介绍

----

`Cattr UI` 是一款基于 `Vue.js 3` 的前端 UI 组件库，主要用于快速开发 PC 网站中后台产品

## 特性

- 基于 `Vue 3.5` 开发的 UI 组件，以 ESM 格式发布，支持 tree-shaking
- 使用 npm + `Vite`（或 `webpack 5`）的工作流
- CSS 样式独立（随组件库发布，位于 `@amazingcat/cattr-ui/src/stylesheet/src/index.scss`），即使使用不同的框架实现，也都能保持统一的 UI 风格
- 提供友好的 API，可灵活的使用组件

## 浏览器支持

- 支持 Vue 3 的现代浏览器（不支持 IE）
- [Electron](http://electron.atom.io/)
- [NW.js](http://nwjs.io)
