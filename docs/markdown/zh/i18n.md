# 国际化

----

`Cattr UI` 组件的文案默认使用英文，如果需要使用其他中文或者其他语言，可以参考下面的方案：

## 指定语言

在安装插件时通过 `locale` 传入语言包：

```js
import { createApp } from 'vue'
import CattrUI from '@amazingcat/cattr-ui'
import '@amazingcat/cattr-ui/src/stylesheet/src/index.scss'    // 引入组件样式
import zhLocale from '@amazingcat/cattr-ui/locale/zh-CN'
import App from './App.vue'

createApp(App)
  .use(CattrUI, { locale: zhLocale })
  .mount('#app')
```

## 兼容 vue-i18n

通过 `i18n` 选项传入翻译函数 `(key, values) => string`。如果函数返回 `null` 或 `undefined`，则使用内置语言包（`en-US` 或通过 `locale` 传入的语言包）中的文案。

```js
import { createApp } from 'vue'
import { createI18n } from 'vue-i18n'
import CattrUI from '@amazingcat/cattr-ui'
import '@amazingcat/cattr-ui/src/stylesheet/src/index.scss'    // 引入组件样式
import enLocale from '@amazingcat/cattr-ui/locale/en-US'
import zhLocale from '@amazingcat/cattr-ui/locale/zh-CN'
import App from './App.vue'

const i18n = createI18n({
  legacy: false,
  locale: 'en',
  fallbackLocale: 'en',
  messages: {
    'en': { ...enLocale },
    'zh': { ...zhLocale }
  }
})

createApp(App)
  .use(i18n)
  .use(CattrUI, { i18n: (key, values) => i18n.global.t(key, values) })
  .mount('#app')
```

> 注意：`i18n.global.t` 对不存在的键会返回键名本身而不是 `undefined`，此时不会回退到内置语言包。请把 `at.*` 的文案加入 vue-i18n 的 `messages`（如上例），或者先用 `i18n.global.te(key)` 判断，不存在时返回 `undefined`。

## 目前支持的语言

| 语言 | 文件名 |
|--- |--- |
| 简体中文 | zh-CN |
| 英语 | en-US |
| 德语 | de |
| 韩语（韩国） | ko-KR |
| 葡萄牙语（巴西） | pt-BR |
| 波斯语（伊朗） | fa-IR |

语言包的引入路径为 `@amazingcat/cattr-ui/locale/<文件名>`（ESM，默认导出）。

如果您需要使用其他的语言，欢迎贡献 PR：只需要在 [这里](https://github.com/cattr-app/ui-kit/blob/master/src/locale/lang/) 添加一个语言配置文件即可
